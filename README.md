# 🏐 2026 빅이큐 MT (ClubMT) - Frontend

이 저장소는 **2026 빅이큐 총동문 MT** 서비스의 프런트엔드 소스 코드를 담고 있습니다. 본 프로젝트는 모든 참가자의 공정한 이용과 데이터 보호를 위해 오픈소스로 투명하게 공개됩니다.

## 🛡️ 투명성 및 보안 정책

본 서비스는 참가 신청, 마니또 매칭, 요리 배틀 투표 등 행사의 핵심 운영을 담당합니다. 소스 코드를 공개하는 목적은 다음과 같습니다.

1.  **공정성 검증**: 마니또 매칭, 요리 배틀 투표 등에서 어떠한 부정 로직이나 조작이 없음을 누구나 코드를 통해 검증할 수 있습니다.
2.  **무결성 유지**: 클라이언트 사이드에서 발생할 수 있는 보안 취약점을 사전에 방지하고 투명한 운영을 지향합니다.

### 🔒 서버 및 데이터 보안 스펙 (Backend Security)

참가자들의 소중한 데이터와 개인정보를 보호하기 위해, 본 서비스의 백엔드 시스템은 다음과 같은 강력한 보안 아키텍처를 기반으로 운영됩니다.

*   **네트워크 격리 (Zero Trust Architecture)**
    *   **Cloudflare Tunnels**: 백엔드 서버는 외부 인터넷망에 직접 노출되지 않으며, Cloudflare의 암호화된 터널을 통해서만 통신합니다. 원본 서버의 IP 주소는 완벽하게 은폐되어 DDoS 및 직접적인 포트 스캐닝 공격을 원천 차단합니다.
    *   **CORS 및 커스텀 헤더 검증**: 허용된 도메인(GitHub Pages)에서 발송되며, 사전에 약속된 커스텀 보안 헤더(`X-ClubMT-Source`)를 포함한 API 요청만 서버가 승인합니다.
*   **개인정보 암호화 (Data Protection)**
    *   **AES-256-CBC**: 참가자의 이름, 연락처 등 민감한 개인정보(PII)는 데이터베이스에 평문으로 저장되지 않고 강력한 양방향 암호화 알고리즘으로 보호됩니다.
    *   **HMAC-SHA256**: 데이터 검색을 위한 해시 역시 안전한 단방향 알고리즘을 사용합니다.
*   **시스템 안정성 (System Integrity)**
    *   **Rate Limiting**: 비정상적인 트래픽이나 매크로 접근을 방지하기 위해 엄격한 IP/유저 기반 호출 횟수 제한(Rate Limit)을 적용하고 있습니다.
    *   **PII Masking Audit Log**: 시스템의 모든 변경 사항은 감사 로그(Audit Log)로 기록되나, 이 과정에서도 개인정보는 마스킹 처리되어 로그 파일 유출 시에도 안전합니다.

# 🏐 2026 빅이큐 MT (ClubMT) - Frontend

이 저장소는 **2026 빅이큐 총동문 MT** 서비스의 프런트엔드 소스 코드를 담고 있습니다. 본 프로젝트는 모든 참가자의 공정한 이용과 데이터 보호를 위해 오픈소스로 투명하게 공개됩니다.

## 🛡️ 투명성 및 보안 정책

본 서비스는 참가 신청, 마니또 매칭, 요리 배틀 투표 등 행사의 핵심 운영을 담당합니다. 소스 코드를 공개하는 목적은 다음과 같습니다.

1.  **공정성 검증**: 마니또 매칭, 요리 배틀 투표 등에서 어떠한 부정 로직이나 조작이 없음을 누구나 코드를 통해 검증할 수 있습니다.
2.  **데이터 보호**: 개인정보는 전송 시 암호화되며, 서버 측에서도 보안 가이드라인에 따라 안전하게 관리됩니다.
3.  **무결성 유지**: 클라이언트 사이드에서 발생할 수 있는 보안 취약점을 사전에 방지하고 투명한 운영을 지향합니다.

## 🚀 기술 스택

- **Frontend**: Vanilla JS, CSS3, HTML5
- **Hosting**: GitHub Pages
- **CI/CD**: GitHub Actions (자동 난독화 및 배포)
- **Backend Interop**: REST API (C# .NET 9)
